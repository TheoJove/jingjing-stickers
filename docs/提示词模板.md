# 表情包生成提示词

## 万能模板（每次只改最后一段）

```
请生成一张 Q 版表情包，正方形 1024×1024，纯白背景。

角色：一只 Q 版蓝色小鲸鱼娘「鲸鲸」。
- 深蓝到浅蓝渐变的长发，头顶一根弯钩呆毛
- 两侧是鲸鱼鳍形状的耳朵，身后一条蓝色鲸鱼尾巴
- 头顶白色蕾丝发带，两侧各一个蓝色蝴蝶结，蝴蝶结中间有小鲸鱼
- 圆脸、蓝色大眼睛带高光、脸颊红扑扑
- 蓝白小女仆裙，围裙正中一只小鲸鱼图案
- 需要时外面套透明黄色连帽雨衣

风格：马卡龙浅蓝主色，线条干净，柔和阴影，Q 版大头小身子，头约占全高一半。
画面：只画这一个角色，居中，四周留白，不要场景、不要英文、不要水印、不要签名。
配字：图下方一行中文「{配字}」，粗圆体、深蓝色字、白色描边，文字要清晰不糊。

【本次表情】情绪：{情绪}；动作：{动作}；配字：{配字}。
```

## 关键技巧

1. **先喂参考图**：把黄雨衣那张（或 qban 任意一张）连同提示词一起发给模型，开头加一句「以下面这张图为角色设计参考，保持发型、发色、鳍耳、尾巴、蝴蝶结完全一致」。
2. **一次只改一个变量**：先出「开心」的标准版，满意了再改表情和动作。不要一口气全生成。
3. **配字控制在 2–5 字**：中文越长越容易糊。真要长句，就分两张。
4. **别让它加英文、数字、logo**。
5. **透明底**：先要纯白背景，生成后我用脚本统一抠图，比让它直接画透明底稳。
