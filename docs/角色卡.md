# 角色卡 · 鲸鲸（源之大肥鱼）

所有表情包生成与后续补图的**唯一外观锚点**。少一个特征，角色就会跑偏。

## 一句话形象

一只 Q 版蓝色小鲸鱼娘，圆脸、大眼睛、软乎乎的，穿一件透明黄色连帽雨衣。

## 必保特征

| 部位 | 描述 |
|---|---|
| 头发 | 深蓝到浅蓝渐变的长发，发梢偏亮蓝，**头顶一根弯钩状呆毛** |
| 耳朵 | 两侧是**鲸鱼鳍形状**的耳朵，白色内衬、蓝色外缘 |
| 尾巴 | 身后一条**蓝色鲸鱼尾巴**，尾鳍浅蓝带白纹 |
| 蝴蝶结 | 两侧各一个**深蓝色蝴蝶结**，蝴蝶结正中一只小鲸鱼 |
| 脸 | 圆脸、蓝色大眼睛带高光、脸颊红扑扑、小嘴张开或抿着 |
| 服装 | **透明黄色连帽雨衣**，兜帽有黄色滚边，帽子顶上是鲸鱼头形状；雨衣上有黄色纽扣和小鲸鱼贴章 |
| 小动作 | 站着时两只小拳头攥在胸前；身边偶尔冒几个浅蓝小气泡 |

## 风格锚点

- Q 版比例：头大身子小，头约占全高一半
- 马卡龙浅蓝 + 奶油黄，线条干净，柔和阴影
- **透明背景**，正方形，角色居中，四周留白
- 不要场景、不要英文、不要水印、不要签名、不要多角色
- 带文字版：图下方一行短中文（2–5 字），粗圆体、深蓝字、白描边
